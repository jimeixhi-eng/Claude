# エキゾチックサプライ 在庫公開サイト＋スタッフ用在庫アプリ

在庫と価格をリアルタイムで公開する Web サイトと、現場スタッフがスマホで「売約済み」を付けるためのアプリをセットにしたもの。

| URL | 内容 |
|---|---|
| `/` | トップ（新着入荷・種類別の件数・ご購入について・店舗情報） |
| `/stock` | 在庫一覧（種類で絞り込み・検索・並び替え・「販売中のみ」） |
| `/item/管理番号` | 個体の詳細（写真・価格・LINE／電話の問い合わせボタン） |
| `/shop` | 店舗情報（地図・イベント出店情報） |
| `/staff/` | スタッフ用アプリ（ホーム画面に追加して使う） |

## 起動

```bash
npm install
npm start          # http://localhost:3000
npm test           # 自動テスト
```

Node.js 22.13 以上が必要。データは `data/`（環境変数 `DATA_DIR` で変更可）に入る。バックアップの対象はこのフォルダだけ。

初めて `/staff/` を開くと、最初の店主アカウントを作る画面が出る。

## 在庫のステータス

| ステータス | サイトでの表示 |
|---|---|
| 販売中 | 表示する |
| 売約済み | 「売約済み」の帯を付けて表示し、一定日数（初期値7日）が過ぎたら自動で消える |
| 非公開 | 表示しない（入荷直後の準備中など） |

価格は「税込価格」で入れる。「価格を公開しない（ASK）」にすると、サイトには「ASK／価格はお問い合わせください」と表示する。

## 権限

| | 店主（最大2名） | スタッフ（最大20名） |
|---|---|---|
| 売約済み・販売中・非公開の切り替え | ○ | ○ |
| 価格・ASK の変更 | ○ | × |
| 生体の登録・編集・削除・写真の追加 | ○ | × |
| リストの取り込み | ○ | × |
| スタッフ管理・店舗情報・変更履歴 | ○ | × |

すべての変更は「誰が・いつ・何を」変えたか履歴に残る（その他 → 変更履歴）。

## スタッフの使い方（売約登録）

1. ホーム画面の「ES在庫」を開く（ログインは最初の1回だけ。180日間保持）
2. 管理番号を打つ（数字キーボードが出る。途中まで打てば候補が出る）
3. 「売約済みにする」を押す → 公開サイトに即反映
4. 押し間違えたら、画面下に出る「取り消す」を押す（8秒間）

### ホーム画面への追加
- iPhone：Safari で `/staff/` を開く → 共有ボタン →「ホーム画面に追加」
- Android：Chrome で `/staff/` を開く →「︙」→「アプリをインストール」

## リストの取り込み（店主）

アプリの「取り込み」タブで、ファイルを選ぶか文章を貼り付ける → 内容を確認 → 取り込む。
**管理番号が同じ生体は上書き**され、番号のない行には自動で番号を振る。

- **Excel（.xlsx）／CSV／TSV**：1行目付近に見出し行があればよい。列の順番は自由。
  見出しは「管理番号（No.）・種名・モルフ・性別・サイズ・価格・分類・CB/WB・ハッチ日・入荷日・備考・写真・状態」などを認識する。
  Excel に貼り付けた写真は、その行の生体の写真として取り込まれる。日本語版 Excel の CSV（Shift_JIS）にも対応。
- **文章（ブログの投稿をそのまま貼り付け）**：1行1個体、または「種名：〇〇」のような項目形式。
  ```
  No.101 ヒョウモントカゲモドキ ハイポタンジェリン ♂ ベビー CB 12,800円
  No.102 ヒョウモントカゲモドキ（マックスノー） ♀ 約10cm 18,000円(税込)
  No.105 フトアゴヒゲトカゲ ハイポトランス ペア ヤング ASK
  ```
  「新入荷のお知らせ」のような生体以外の行は自動で除外され、確認画面に一覧で表示される。

見本：`samples/blog-sample.txt`、`samples/list-sample.csv`、`samples/list-sample.xlsx`

種類（ヤモリ・トカゲ・ヘビ・カメ・両生類など）が空欄の場合は、種名から推測して入れる。

## 設定（その他 → 店舗情報・サイト設定）

店名、住所、営業時間、定休日、電話、LINE の URL、Google マップ、お知らせ帯、イベント出店情報、**第一種動物取扱業の標識**（登録番号などを入れるとフッターに表示）、新着の日数、売約済みを残す日数、種類の一覧。

## 仕組み

- Node.js（Express）＋ SQLite（Node 標準の `node:sqlite`）。外部のデータベースサービスは不要。
- 在庫が変わると Server-Sent Events で、開いている公開ページとスタッフアプリへ即時に通知する（ページの再読み込みは不要）。
- スタッフアプリは PWA。画面を端末に保存するので起動が速く、通信は在庫データだけ。写真は送る前にスマホ側で縮小する。

## 公開（本番）

常時起動するサーバーと、消えないディスク（`DATA_DIR`）が必要。

- VPS（さくら・ConoHa・Xserver VPS など）：`npm ci --omit=dev && npm start` を pm2 や systemd で常駐させ、nginx で HTTPS 化する
- Docker：`docker build -t exotic-supply . && docker run -d -p 3000:3000 -v es-data:/data exotic-supply`
- Render／Fly.io など：永続ディスクを `/data` にマウントする

nginx を前に置く場合、`/events` はバッファリングを無効にする（アプリ側で `X-Accel-Buffering: no` を送っている）。
**HTTPS は必須**（スタッフアプリのインストールとログインの安全のため）。
